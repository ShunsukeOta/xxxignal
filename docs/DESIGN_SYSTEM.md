# xxxignal Design System

## Principles

- モノクロ主体
- Noto Sans JPのみを使用
- PC / SPで情報設計を共通化
- SPは片手操作を優先
- 8px前後の角丸、1px境界線を基本とする
- 装飾より状態・優先順位・可読性を優先
- デモ値を差し込まず、未取得は0 / 未接続 / 未設定で表現

## Typography

- Font family: Noto Sans JP
- Page title: 28px / 700 (SP 23px)
- Section title: 15–17px / 700
- Body: 14px / 400
- UI text: 12–13px / 500–600
- Caption: 10–11px / 400–600
