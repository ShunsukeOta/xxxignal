# xxxignal Design System

## Principles

- Monochrome主体
- Noto Sans JPのみ使用
- PC / SPで情報構造を共通化
- SPは片手操作を優先
- 8px前後の角丸、1px境界線
- 装飾より状態・優先順位・可読性
- デモ値を入れない

## Typography

- Noto Sans JP
- Page title: 28px / 700 (SP 23px)
- Section title: 15–17px / 700
- Body: 14px / 400
- UI: 12–13px / 500–600
- Caption: 10–11px

- Modal / SP full-screen sheet

- Research list row
- Research search
