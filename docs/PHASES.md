# xxxignal MVP — 5 Phases

## Phase 1 — Core Foundation ✅

Goal: 将来の配布・販売に耐える土台で、最大3アカウントの運用設計を登録できる。

- React / Vite / TypeScript
- Cloudflare Worker + Hono
- D1 + Drizzle ORM
- User / Workspace / Membership
- X Account CRUD（物理削除なし）
- Account Strategy
- Voice Profile
- Workspace Settings
- Audit Log
- Cloudflare Access境界
- PC/SP responsive UI
- 外部APIコスト 0円

## Phase 2 — Research & X Viewer

Goal: X APIを使わず、公開情報と外部SourceをResearch Poolへ集約する。

- Public X link / official embed
- RSS / Web Source
- Manual URL capture
- Competitor / Target Account registry
- Shared Research Pool
- Topic categorization

## Phase 3 — Content Studio

Goal: Research → Angle → Draft → Human Edit / Approveを完成させる。

- AI Provider adapter
- Draft versioning
- Voice memory
- Duplicate guard
- Reject feedback
- Manual publish assist

## Phase 4 — X OAuth, Analytics & Cost

Goal: 3アカウントを公式OAuthで接続し、必要最小限のX APIだけ利用する。

- X OAuth
- Metrics
- Account Health
- Cost ledger / budget guard
- API cache
- Engagement candidate inbox

## Phase 5 — Production MVP

Goal: 3アカウントを毎日1人で運用できる。

- Opportunity ranking
- Calendar / Queue
- Weekly learning
- Cross-account duplicate / engagement guard
- Conversion / Revenue attribution foundation
- Export / backup
